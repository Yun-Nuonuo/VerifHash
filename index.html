Development Roadmap

From the first idea to mainnet.

  1. 01

    Foundation

    Menentukan nama proyek, ticker, algoritma mining, tujuan proyek, dan aturan dasar koin.

  2. 02

    Source Code & Fork

    Memilih source code dasar, melakukan fork repositori, menyesuaikan identitas proyek, dan melakukan build awal.

  3. 03

    Core Configuration

    Mengatur parameter konsensus, block time, block reward, halving, suplai maksimum, dan genesis block.

  4. 04

    Mining Test

    Menjalankan node, menguji proses mining, memverifikasi pembuatan blok, dan memastikan reward bekerja sesuai aturan.

  5. 05

    Testnet

    Menguji komunikasi antarnode, kestabilan jaringan, sinkronisasi blok, serta memperbaiki bug sebelum peluncuran.

  6. 06

    Mainnet Launch

    Meluncurkan jaringan utama setelah implementasi dan pengujian memenuhi kriteria kesiapan.
